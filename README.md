# po

API TMDB cálculo online para StreamElements.

## Exemplos do comando

Filme com ano:

```text
!calculo a mumia 1999
```

Série/anime/desenho com ano e temporada:

```text
!calculo perdidos no espaço 2018 T1
```

Também continua aceitando o jeito antigo para série:

```text
!calculo nome da serie 1
```

## Formatos aceitos para temporada

```text
T1
t1
S1
temporada 1
temp 1
```
